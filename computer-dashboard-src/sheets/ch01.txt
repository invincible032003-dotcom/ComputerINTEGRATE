## 60-second recap
- ★ **Generations:** vacuum tube → transistor → IC → microprocessor (VLSI) → AI (ULSI). One device per generation.
- ★ **CPU = ALU + CU + registers.** ALU calculates and compares; CU fetches, decodes and directs but computes nothing.
- ★ **PC** holds the address of the **next** instruction; **IR** holds the **current** one; the **accumulator** holds ALU results.
- ★ **Speed:** registers > cache > RAM > SSD > HDD > optical/tape. **Size and cheapness** run the other way.
- ★ **RAM** volatile (DRAM = main memory, SRAM = cache); **ROM** non-volatile (BIOS). Secondary storage is non-volatile.
- ★ **Boot:** power on → BIOS → POST → boot loader (MBR) → kernel → login. **CMOS** keeps settings and the clock.
- ★ **Instruction cycle:** fetch → decode → execute → store (four steps).

## Generations of computers
- **1st (1946–56): vacuum tubes**, machine language, punched cards, magnetic drums. ENIAC, EDVAC, UNIVAC-I (first commercial).
- **2nd (1956–63): transistors**, assembly language, FORTRAN/COBOL, magnetic-core memory. IBM 1401, IBM 7090.
- **3rd (1964–71): integrated circuits (SSI/MSI)**, keyboards + monitors, operating systems, multiprogramming. IBM System/360.
- ★ **4th (1971–now): microprocessors (LSI/VLSI)**; the Intel 4004 (1971) was the first microprocessor. PCs, GUIs, networks, the WWW.
- **5th (present/future): AI, ULSI, parallel processing**, natural-language interfaces. If "5th" is not an option, pick the latest one listed.
- Memory hook: **Tube → Transistor → IC → Microprocessor → AI**.

## Types of computers
- **By working principle:** analog (continuous quantities, e.g. speedometer), digital (discrete 0/1), hybrid (both, e.g. ICU monitors).
- **By size and power:** supercomputer > mainframe > minicomputer > microcomputer (PC).
- ★ **Supercomputer:** weather forecasting, nuclear and climate simulation; speed in **FLOPS**; many processors in parallel. India: PARAM (C-DAC, 1991), Pratyush, Mihir.
- **Mainframe:** banks, railways, census — thousands of users and transactions at once, high reliability.
- **Embedded computer:** a dedicated processor inside a device (washing machine, ATM, car ECU), program in ROM/firmware.

## The machine: CPU, ALU, CU
- ★ **CPU = ALU + CU + registers.** The ALU is part of the CPU; the CU is not part of the ALU.
- ★ **ALU:** arithmetic (+ − × ÷) and logic (AND, OR, NOT, comparisons). AND/OR happen in its **logic unit**.
- **CU:** fetches, decodes, sequences and issues control signals — the "manager". It performs no calculation.
- ★ **Accumulator:** register that receives ALU results. **Program counter:** address of the next instruction.
- **Clock speed** is in Hz (GHz today); cycle time = 1 / frequency (1 GHz → 1 ns). **Multi-core** = several complete cores on one chip.
- **Word size** = bits processed at once (32-bit, 64-bit); a 32-bit address reaches 2³² bytes = 4 GB.

## Memory essentials
- **Hierarchy (fastest → slowest):** registers → cache (L1 < L2 < L3) → RAM → SSD/HDD → optical/tape.
- ★ **RAM:** volatile, read/write, random access. **DRAM** = capacitor, needs refresh, cheap → main memory. **SRAM** = flip-flops, no refresh, fast, costly → cache.
- **DDR SDRAM** transfers on both clock edges (Double Data Rate). **VRAM** buffers the image for the display.
- ★ **ROM:** non-volatile. PROM (write once), EPROM (UV erase), EEPROM (electrical erase), flash (block-erasable EEPROM).
- **Virtual memory** uses disk as an extension of RAM through **paging**: a large address space, not extra disk.
- **Units:** 1 byte = 8 bits, 1 nibble = 4 bits; KB → MB → GB → TB → PB, ×1024 each (2¹⁰). Speed → hertz; size → bytes.

## Buses, motherboard, BIOS and booting
- ★ **System bus = data bus (bidirectional) + address bus (unidirectional, CPU → memory) + control bus** (read/write, interrupt, clock).
- Address lines decide addressable memory: n lines → $2^n$ locations (1024 locations → 10 lines).
- **Motherboard:** CPU socket, chipset (northbridge: CPU/RAM/GPU; southbridge: I/O), RAM slots, BIOS chip, CMOS battery; expansion slots (PCI/PCIe).
- ★ **BIOS** (firmware in ROM/flash) runs the **POST**, initialises hardware, boots the system and gives basic hardware-independent device access.
- ★ **Boot sequence:** power on → BIOS/UEFI → POST → boot loader (MBR, 512 bytes) → OS kernel loaded → login.
- **CMOS** stores BIOS settings and the real-time clock; a coin-cell battery keeps it alive.
- **PSU** converts AC mains to regulated DC; it powers components but never touches data.

## Secondary storage
- **HDD:** platters → tracks (circles) → sectors (arcs); same track on all surfaces = cylinder. Arm positions heads; spindle motor spins platters.
- ★ **SSD** (flash): faster, silent, lower power and heat, shock-proof, more reliable — but **costlier per GB** (low price is not an advantage).
- **Optical (laser):** CD (~700 MB), DVD (4.7 GB single layer), Blu-ray (25 GB, blue-violet laser). CD-ROM read-only · CD-R write once · CD-RW rewritable (phase change).
- ★ **Magnetic tape:** sequential access, cheapest per GB — the classic **auxiliary / backup** medium.
- **Floppy (3.5-inch)** = 1.44 MB: removable but slow and tiny.

## Software, OS and the instruction cycle
- **System software** (OS, drivers, utilities, translators) vs **application software** (word processor, spreadsheet, browser).
- **Firmware** is software in ROM (BIOS); **utility software** covers antivirus, backup, compression and disk tools.
- **OS functions:** process, memory, file and device management; security; user interface. The OS is the **resource manager**.
- ★ **Kernel** = core of the OS, always in RAM, talks to hardware. **Shell** = command interpreter / user interface.
- ★ **Machine / instruction cycle:** fetch → decode → execute → store (write back). Each machine-language instruction takes one cycle, so 6 instructions = 6 cycles.

## ★ Most-tested facts
- The ALU is a component of the CPU; the control unit is **not** a component of the ALU.
- The register that tracks the next instruction is the **program counter**.
- Data processing is done by the **CPU together with memory**; the monitor is output only.
- Machine cycle: **four phases**, executes machine-language instructions, one cycle per instruction.
- Main CPU operations: **fetch, decode, execute, store** — all four.
- BIOS: **POST + booting + hardware-independent device access** — all three.
- AND/OR operations happen in the **logic unit of the ALU**; ALU results are stored in the **accumulator**.
- Auxiliary memory → **magnetic tape**. Disk capacity = surfaces × tracks × sectors × bytes, e.g. 16 × 256 × 16 × 512 = **33,554,432 bytes** (32 MB).

## Traps to avoid
- The **control unit does not compute**; any statement giving arithmetic to the CU is false.
- **Address bus is one-way**, data bus two-way. The number of address lines sets capacity, not word size.
- **SRAM → cache, DRAM → main memory**; do not swap them. **Cache is smaller than RAM**, always.
- **ROM is not volatile**; "erasable" ROMs (EPROM/EEPROM) are still non-volatile.
- The **motherboard connects**; the **CPU controls and coordinates**. "Coordinates all hardware" → CPU.
