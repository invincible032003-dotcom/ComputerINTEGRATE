## Number systems at a glance
- **Base (radix) r uses digits 0 … r−1.** The highest digit is **one less than the base** (ISS 2022). A digit ≥ base (e.g. G in hex, 8 in octal) makes the number invalid (ISS 2020: 15F6G is not hex).
- Binary (2): 0–1 · Octal (8): 0–7 · Decimal (10) · Hexadecimal (16): 0–9, A=10 … F=15.
- **Grouping shortcut:** 1 octal digit = **3 bits**, 1 hex digit = **4 bits**. Group from the point outwards, padding with zeros at both ends.
- **Any base → decimal:** sum of digit × $r^{position}$ (fraction positions −1, −2 …). $(325.12)_8$ = 213 + 1/8 + 2/64 = **213.15625** (ISS 2018).

## Conversion toolkit
- **Decimal → base r (integer part):** divide by r repeatedly and read the remainders **bottom-up**.
- **Decimal → base r (fraction):** multiply by r repeatedly and read the integer parts **top-down**.
- **Octal ↔ hex:** go through binary. $(6251)_8$ = 110 010 101 001 → 1100 1010 1001 = **CA9** (ISS 2021, 2023).
- $(32FC.75)_{16}$ → binary → regroup in 3s → **$(31374.352)_8$** (ISS 2022).
- $(111110111.110101)_2$ = 1 1111 0111 . 1101 0100 = **1F7.D4** (ISS 2020).
- $(366)_8$ = **0F6** hex; $(A53)_{16}$ = **2643** decimal (ISS 2025). $45796_{10}$ = **131344** octal; $(365)_8$ = **0F5** hex (ISS 2026).
- **Unknown base:** $(110)_X = (1100)_2 = 12$, so $X^2 + X = 12$ and **X = 3** (ISS 2023).

## Binary arithmetic
- **Addition:** 0+0=0, 0+1=1, 1+1=10 (write 0, carry 1), 1+1+1=11.
- **Subtraction:** 0−1 = 1 with a borrow of 1. In practice, add the 2's complement.
- **Division check:** 217 ÷ 12 → quotient 18 = **10010**, remainder 1 = **0001** (ISS 2019).
- **AND / OR / XOR of binaries:** do it bit by bit. 100101 AND 101101 = **100101** (ISS 2021).

## Complements and signed numbers
- **1's complement:** flip every bit. **2's complement:** 1's complement + 1 (or copy bits up to and including the first 1 from the right, then flip the rest).
- **−59 in 8-bit 2's complement:** 59 = 00111011 → flip → 11000100 → +1 → **11000101** (ISS 2022, 2024).
- **n-bit signed range (2's complement):** $-2^{n-1}$ to $2^{n-1}-1$. The largest in an 8-bit word is **127** (ISS 2018); in general $2^{n-1}-1$ (ISS 2018).
- 2's complement is preferred because it has a single zero (so more numbers fit), faster arithmetic (subtraction = addition) and easy negatives (ISS 2018: all three reasons).
- **r's and (r−1)'s complement in decimal:** 9's complement of 47 = 52, and **10's complement of 47 = 53** (ISS 2024).

## Codes
- **Weighted codes:** BCD **8421**, 2421, 5211 (ISS 2019, 2020). **Non-weighted:** Gray, Excess-3, ASCII.
- **BCD:** each decimal digit becomes 4 bits. 0101 0010 0001 . 0110 = **521.6** (ISS 2020). The 4-bit BCD code is the **8421 code** (ISS 2018).
- **Excess-3** = BCD + 3 (0011). It is self-complementing.
- **Binary → Gray:** keep the MSB, then XOR each adjacent pair. 01010010 → **01111011** (ISS 2023).
- **Gray → binary:** keep the MSB, then each binary bit = previous binary bit XOR the current Gray bit. 10101110 → **11001011** (ISS 2021).
- Gray code: successive values differ in **one bit** (used in encoders and K-maps). ASCII = 7-bit (128 characters); Unicode for all scripts.

## Floating point
- **Normalised form:** mantissa with its leading digit just after the point. 11.234 → **.11234E+2** (ISS 2018).
- IEEE 754 single precision = 1 sign + 8 exponent (bias 127) + 23 mantissa bits; double = 1 + 11 (bias 1023) + 52.

## Traps to avoid
- Read fraction digits **top-down** when converting; integer remainders are read **bottom-up**.
- Pad binary groups from the **point outwards**: leading zeros on the left, trailing zeros on the right.
- Hex **A–F are digits 10–15**; any letter after F makes the number invalid.
