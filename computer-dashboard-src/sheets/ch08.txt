## 60-second recap
- ★ **ARPANET 1969** → TCP/IP 1983 → **WWW** (Berners-Lee, CERN, 1989; public 1991). Web = HTML + HTTP + URL.
- ★ **Ports:** HTTP 80 · HTTPS 443 · FTP 20/21 · SMTP 25 (send) · POP3 110 · IMAP 143 (receive) · DNS 53 · SSH 22 · Telnet 23.
- ★ **DNS** name → IP · **DHCP** gives IP · **ARP** IP → MAC. IP = logical address; MAC = hardware address.
- ★ **Hub** repeats · **switch** forwards by MAC · **router** by IP · **gateway** joins dissimilar networks · **modem** D↔A.
- ★ **Fibre** = fastest, highest bandwidth, EMI-immune. **Wi-Fi** = IEEE 802.11.
- ★ **Virus** needs a host · **worm** self-spreads · **Trojan** disguised · **ransomware** encrypts · **phishing** fake site/mail.

## Internet foundations
- ★ **ARPANET (1969, US DoD):** the first packet-switched network and forerunner of the internet. The switch to **TCP/IP** happened on 1 January 1983. **NICNET** is the Government of India's network, built by NIC.
- **WWW:** Tim Berners-Lee, CERN, proposed 1989, public 1991, royalty-free 1993. The **first browser was WorldWideWeb**; the first popular graphical one was Mosaic.
- **IPv4** = 32-bit, dotted decimal; **IPv6** = 128-bit, hexadecimal with colons. The move to IPv6 is driven by **address exhaustion**.
- **ICANN/IANA:** names and numbers. **IETF:** protocol standards (RFCs). **W3C:** web standards. **IEEE 802:** LAN and Wi-Fi.
- ★ An **IP address** is a logical address; a **MAC address** is the hardware address ("IP = hardware address" is false).

## Protocols and ports
- ★ **Application layer:** HTTP (80), **HTTPS (443, TLS)**, FTP (20/21), **SMTP (25, sending mail)**, **POP3 (110)**, **IMAP (143, retrieval)**, DNS (53), DHCP, Telnet (23), SSH (22).
- ★ **Transport:** TCP (connection-oriented, reliable) and UDP (connectionless, fast). **Network/internet layer:** IP, **ICMP, ARP**. ARP finds the MAC address for an IP address and is **not** an application protocol.
- ★ **DNS** turns names into IP addresses; **DHCP** assigns IP addresses automatically.
- ★ Network protocols handle **error detection and correction, initiation and termination, message formatting** and the type of physical connection.

## Network hardware and topologies
- ★ **Hub** (repeats to all ports; the centre of a star) · **switch** (forwards by MAC address) · **router** (connects networks and forwards IP packets by destination address) · **bridge** (joins LAN segments) · **repeater** (regenerates signal) · **gateway** (joins dissimilar networks and converts protocols).
- ★ **Modem** converts digital ↔ analog; **NIC** connects a computer to a network or the internet.
- ★ **Topologies:** **bus** (single backbone cable) · **star** (hub failure brings down everything; easy fault detection) · ring · **mesh** (most robust). One computer failing doesn't affect the others in **bus, star and mesh**.
- ★ **Media:** twisted pair < coaxial < **optical fibre** (fastest, highest bandwidth, immune to EMI). Wireless: **Wi-Fi = IEEE 802.11**, **802.11ad** fastest of the common standards; Bluetooth = 802.15.1.

## Connections and services
- ★ Dial-up (≤ 56 kbps) < DSL (phone line, always on) < cable (coaxial) < fibre. **Leased line** = dedicated, always on, symmetric, low latency. **Satellite** reaches remote areas but has high latency and rain fade.
- **URL** = scheme :// host / path ? query # fragment. Search engines crawl, index and rank (Google's PageRank). **Cookies** are small text files that remember the user.
- **E-mail:** SMTP to send, POP3/IMAP to receive (Ray Tomlinson, 1971, the @ sign). **VPN** = an encrypted tunnel over the public internet. **Cloud storage:** Dropbox, Drive, OneDrive.
- ★ **IPsec:** application-independent security at the IP layer; router-to-router IPsec is called **tunnelling**.
- **Mobile OS:** Android (Google, Linux kernel, open source, largest share) · iOS (Apple, privacy focus).

## Security and malware
- ★ **Virus:** needs a host program and user action. **Worm:** spreads by itself with no user interaction. **Trojan:** disguised as useful software, doesn't replicate. **Polymorphic virus:** changes its code on each infection.
- ★ **Spyware** gathers data secretly · **adware** shows ads · **ransomware** encrypts and demands payment (WannaCry) · **keylogger** records keystrokes · **botnet** = zombie machines (DDoS) · **logic bomb** waits for a trigger · **rootkit** hides admin access.
- ★ **Phishing:** a fake e-mail or site steals credentials. **Eavesdropping:** wiretap listening. **Steganography:** data hidden inside images.
- ★ **Cryptography:** symmetric = one secret key (**DES**, AES); asymmetric = public + private key (RSA); a **digital signature** uses a private/public key pair. Encryption turns plaintext into ciphertext, not the reverse.
- ★ **Non-repudiation:** neither sender nor receiver can deny a message. **Firewall** terms: gateway, proxy server, screening router; a **packet-filter firewall** checks every IP packet.
- ★ **ISO/IEC 27001** is the standard for information security management. **Antivirus** is **utility** software. India: **IT Act, 2000**.

## ★ Most-tested facts
- Send mail → **SMTP**; retrieve mail → **IMAP** (or POP3); mail ports → **25, 110, 143**.
- Not an application-layer protocol → **ARP**; application layer → **SMTP, FTP, DHCP** (not IP or TCP).
- Not a web browser → **Apple iOS** (an operating system).
- Fastest medium / highest bandwidth → **optical fibre**.
- Devices that connect networks → **repeater, bridge, hub** (Bluetooth is a wireless standard, not a device).
- A router connects networks and forwards packets by destination IP address.

## Traps to avoid
- **SMTP sends; POP3/IMAP receive.** IMAP keeps mail on the server, POP3 downloads it.
- A **firewall filters traffic**; it is not an antivirus. **HTTPS** is HTTP over TLS encryption, not "HTTP + password".
- The worm vs virus difference is **user interaction**: a worm needs none.
- **URL** starts with **Uniform**, not "Universal".
