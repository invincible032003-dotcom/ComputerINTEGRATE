Q: Which generation of computers used vacuum tubes for circuitry?
a) First generation
b) Second generation
c) Third generation
d) Fourth generation
K: a
X: First-generation computers (about 1946–1958, e.g. ENIAC, UNIVAC) used vacuum tubes for circuitry and magnetic drums for memory; they were huge, power-hungry and produced a lot of heat.
S: Vacuum tube → 1G · Transistor → 2G · IC → 3G · Microprocessor (VLSI) → 4G · AI / ULSI → 5G.

#46 p16 a48
Q: How is the processing power of a CPU measured?
a) Number of clock cycles per second
b) Number of instructions executed per second
c) Number of cache memory accesses per second
d) Number of registers in the CPU
K: a
X: Processing power is quoted as clock frequency — cycles per second, in MHz or GHz. Throughput can also be given in MIPS (millions of instructions per second) or FLOPS, but clock speed is the headline figure on every processor.

S: Cycle time = 1 / clock frequency (1 GHz → 1 ns).

X: Operands are read from CPU registers or from RAM; for memory operands the address is placed in the memory address register (MAR) and the data arrives in the memory data register (MDR).

Q: How many steps are involved in the instruction cycle while executing a program?
a) Two steps
b) Three steps
c) Four steps
d) Five steps
K: c
X: The standard instruction cycle has four steps: fetch, decode, execute and store (write back). Some texts compress it to fetch–execute or add an operand-fetch step, but four is the expected count.
