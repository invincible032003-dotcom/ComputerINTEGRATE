#1 p319 a336
Q: Which of the following protocols is commonly used for sending and receiving emails?
a) HTTP
b) FTP
c) SMTP
d) DNS
K: c
X: SMTP (Simple Mail Transfer Protocol) is the standard protocol for email. Strictly, SMTP sends mail and servers use it to relay mail; mailboxes are read with POP3 or IMAP. HTTP serves web pages, FTP transfers files and DNS resolves names.
S: Send mail → SMTP (25); receive mail → POP3 (110) / IMAP (143).

#11 p320 a337

b) NSFNET
c) Internet2
d) World Wide Web
K: a
X: ARPANET (US Department of Defense's ARPA, 1969) was the first wide-area packet-switched network and the forerunner of the internet. NSFNET (1985) later became the backbone. The WWW (1989–91) is a service that runs on the internet, not a network.
S: Packet switching first → ARPANET (1969).

#13 p320 a337
Q: The transition from IPv4 to IPv6 was primarily driven by:
a) The need for increased security
b) The depletion of available IPv4 addresses
c) The demand for faster internet speeds
d) The emergence of cloud computing
K: b
C: C7
X: IPv4 has 32-bit addresses (about 4.3 billion), which have run out. IPv6 uses 128-bit addresses (about 3.4 × 10^38). Better security (built-in IPsec) is a side benefit, not the driver.
S: IPv4 = 32-bit (dotted decimal); IPv6 = 128-bit (hex, colons).
