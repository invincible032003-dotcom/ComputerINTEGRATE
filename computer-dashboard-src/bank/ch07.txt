#1 p294 a308
Q: What is an operating system?
a) A collection of hardware components
b) A programming language
c) Software that manages computer hardware and software resources
d) A graphical user interface
K: c
X: An operating system is system software that sits between the user and the hardware. It manages the CPU, memory, I/O devices and files, and provides services to application programs.
S: OS = resource manager + user–hardware interface.

#2 p294 a308
Q: Which of the following is not an operating system?
a) Windows
b) Linux
c) Microsoft Office
d) macOS
K: c
X: Microsoft Office (Word, Excel, PowerPoint) is an application suite that runs on top of an operating system. Windows, Linux and macOS are operating systems.
S: Office / Tally / browsers = application software, not OS.

#3 p294 a308
Q: What is the purpose of an operating system?
a) To provide a user interface for interacting with the computer
b) To manage and allocate computer resources
c) To prevent unauthorized access to the system
d) To create and edit documents
K: b
X: The core purpose is to manage and allocate resources (CPU time, memory, I/O devices, files) efficiently and fairly among programs and users. The user interface and security are important but secondary functions, and editing documents is an application task.
S: Primary purpose of OS = resource management.

#4 p294 a308
Q: Which of the following is not a type of operating system?
a) Single-user operating system
b) Multi-user operating system
c) Real-time operating system
d) Web-based operating system
K: d
X: The traditional classes of OS are single-user, multi-user, batch, time-sharing, real-time, network and distributed. A "web-based OS" is a recent idea and is not one of the textbook types.
S: Textbook OS types: batch · multiprogramming · time-sharing · real-time · network · distributed.

#5 p294 a308
Q: Which scheduling algorithm is used in most operating systems to determine the execution order of processes?
a) Round-robin scheduling
b) First-come, first-served (FCFS) scheduling
c) Shortest Job Next (SJN) scheduling
d) Priority-based scheduling
K: a
X: Round robin gives each ready process a fixed time slice (quantum) in turn, which makes it the standard algorithm for time-sharing systems. Modern desktop OSs actually combine priorities with round robin (multilevel feedback queues), but among these options the book's answer is round robin.
S: Time slice / quantum → round robin.

#6 p294 a308
Q: What is virtual memory in an operating system?
a) Memory that is physically installed in the computer
b) Memory used for storing virtual machines
c) A technique that allows the execution of processes that are not completely in memory
d) Memory used exclusively for system processes
K: c
X: Virtual memory uses part of the disk as an extension of RAM. Only the pages a process currently needs are kept in main memory, so a program larger than physical RAM can still run. Pages move between RAM and disk by paging/swapping.
S: Virtual memory = RAM + disk illusion; process need not be fully in RAM.

c) To manage and organize files on storage devices
d) To regulate network connections
K: c
X: The file system decides how files and directories are named, stored, organised and retrieved on disks and other storage devices (e.g. FAT32, NTFS, ext4).
S: File system = organise files on storage.

S: Memory mgmt = allocate + deallocate + protect + virtual memory.

#22 p296 a310
Q: What is the role of the kernel in an operating system?
a) Managing input/output devices
b) Managing file systems
c) Providing a user interface
d) Core component responsible for managing system resources
K: d
X: The kernel is the core of the OS. It stays in memory and manages the CPU, memory, devices and system calls. The user interface is provided by the shell, not the kernel.
S: Kernel = core; shell = interface.

S: Hardware device control → device drivers.

#61 p301 a313
Q: What is the purpose of context switching in a multiprogramming operating system?
a) Loading a new program into memory
b) Saving and restoring process state
c) Handling input/output operations
d) Allocating memory resources
K: b
X: A context switch saves the running process's state (program counter, registers) in its Process Control Block (PCB) and loads the saved state of the next process. It is pure overhead: no useful work is done during the switch.
S: Context switch = save PCB + load PCB (overhead).
