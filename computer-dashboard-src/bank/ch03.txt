#1 p138 a168
Q: Which unit of a computer system is responsible for executing instructions and performing calculations?
a) Central Processing Unit (CPU)
b) Random Access Memory (RAM)
c) Input/Output (I/O) Unit
d) Secondary Storage Unit
K: a
X: The CPU fetches, decodes and executes every instruction: its control unit directs, and its ALU does the calculations. RAM only stores, the I/O unit only moves data in and out, and secondary storage keeps data permanently. None of them executes anything.
S: "Executes" anything → CPU (brain). Stores → memory. Moves in/out → I/O.

b) Random Access Memory (RAM)
c) Control Unit
d) Arithmetic Logic Unit (ALU)
K: b
X: RAM (main memory) holds the data and instructions of running programs, close enough for the CPU to fetch them in nanoseconds. The CPU, control unit and ALU process data; they are not the store the question asks about.
S: CPU's working desk → RAM.
