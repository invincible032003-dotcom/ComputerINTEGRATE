#1 p195 a225
Q: Which number system is commonly used by computers to store and process data?
a) Binary
b) Decimal
c) Hexadecimal
d) Octal
K: a
X: Computers store and process everything in binary (base 2), because electronic circuits have two stable states — on/off, high/low voltage.
S: Hardware thinks in 2 states → binary.

#2 p195 a225
Q: The binary number system uses digits:
a) 0 and 1
b) 0 to 9
c) A to F
d) 1 to 8
K: a
X: Base 2 uses exactly two digits, 0 and 1.
S: Base b uses digits 0 … b−1 (binary 0–1, octal 0–7, decimal 0–9, hex 0–F).
