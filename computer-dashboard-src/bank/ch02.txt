Q: Which of the following is not considered an input device for a computer?

b) Mouse
c) Monitor
d) Scanner
K: c

S: Monitor, printer, speaker, plotter → output; keyboard, mouse, scanner, mic, webcam → input.

#2 p74 a105
Q: Which component of a computer is responsible for temporarily storing data that can be accessed quickly?
a) CPU
b) RAM
c) Hard Drive
d) Power Supply
K: b
X: RAM is the fast, temporary working store: it holds the data and instructions in current use and loses them at power-off. The CPU processes rather than stores, the hard drive is permanent but slow, and the power supply only supplies electricity.
S: Temporary + fast → RAM; permanent + slow → hard drive.

a) Input
b) Output
c) Storage
d) Encoding
K: d
X: Encoding converts information (characters, sound, images) into a coded binary form, such as ASCII or Unicode, that the computer can process.
S: Human form → machine code = encoding; machine code → human form = decoding.

b) GPU
c) RAM
d) Motherboard

S: Brain = CPU; graphics = GPU; memory = RAM; backbone = motherboard.

Q: Which type of architecture is generally more suitable for applications that require high performance and efficiency?
a) RISC
b) CISC
c) Both RISC and CISC are equally suitable
d) Neither RISC nor CISC is suitable for high-performance applications
K: a
X: The book keys RISC: streamlined instructions, pipelining and power efficiency give high performance per watt.
S: Performance + efficiency → RISC (book answer).

Q: Which of the following is a disadvantage of RISC architecture?
a) Limited instruction set flexibility
b) Increased complexity of instruction execution
c) Larger program size
d) Slower clock speeds compared to CISC processors
K: a
X: With only simple instructions, complex operations need sequences of instructions — limited flexibility of the instruction set. Larger program size (c) follows from the same limitation.
S: RISC cons: limited instructions → longer programs.
